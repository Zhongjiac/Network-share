# 🚀 局域网极速快传 (LAN Fast Share)

基于 Rust 高性能异步并发引擎 [sigoden/dufs](https://github.com/sigoden/dufs) 与智能物理网卡识别算法构建的局域网免客户端极速文件互传方案。无需安装微信/QQ，不耗费外网流量，支持手机、平板、电脑跨设备极速互联。

---

## 🌟 核心特性

- **现代化网盘级 UI（媲美 AList / 阿里云盘）**：
  - 100% 纯本地离线原生 ES6+/CSS3，零外网 CDN 与第三方网络依赖，断网也能秒开；
  - 现代毛玻璃质感与微动效，支持一键切换 **浅色模式 / 深色模式**；
  - 列表视图与网格视图（图片缩略图实时渲染）无缝切换；
  - 实时文件名过滤、排序（名称/大小/时间）与多级可点击面包屑导航；
  - 全屏高亮拖拽批量上传。
- **专业级传输任务中心**：
  - 右下角常驻悬浮胶囊，实时监控总上传/下载速度与进行中任务数；
  - 折叠抽屉面板分设【上传列表】与【下载列表】两个独立队列；
  - 实时进度条、已传/总大小、EWMA 算法平滑瞬时速率与精确剩余时间 (ETA)；
  - **断点续传与暂停/继续**：
    - **上传**：基于 `HEAD` 探测服务端落盘字节 + `PATCH` 追加模式 (`X-Update-Range: append`)，暂停后点继续直接从断点续传！
    - **下载（全新纯网页内置零泄漏流式架构）**：坚决不调用浏览器原生下载接管，所有任务统一由网页“传输任务中心”队列调度；采用零泄漏生命周期管理（落盘后立刻清空 `chunks` 引用并撤销 ObjectURL），严格并发槽位隔离（专属 2 并发）彻底杜绝 OOM；UI 采用局部 DOM 精准微更新与 200ms 时间戳节流，大文件、多文件高速下载主线程丝滑流畅；完美支持 HTTP 206 `Range: bytes=offset-` 网页内自由暂停与真·断点续传！
  - 全局队列控制：【全部暂停】、【全部开始】、【清空已完成】，支持最大并发控制。
- **多选与悬浮批量操作坞 (Batch Action Dock)**：
  - 支持单选、全选与 `Shift` 键连选，底部平滑滑出操作坞，支持批量流式下载、批量删除与打包下载。
- **多媒体与代码在线预览 (Lightbox)**：
  - 支持图片大图查看、音视频 HTML5 流媒体即时点播（支持 Range 拖动秒播）、文本/代码等宽高亮查看。
- **精准物理网卡识别算法**：
  - 智能算法自动剔除 WSL、VMware、VirtualBox、VPN、Npcap、蓝牙及 Clash/代理 TUN 等虚拟网卡，100% 精准锁定路由器分配的真实物理局域网 IP。
- **100% 离线纯矢量高保真二维码引擎 (全新升级)**：
  - 前端内置轻量纯原生 JS QR 算法引擎，严格遵循 ISO/IEC 18004 国际标准，配置 4 模块纯白安全静区与 M 级纠错；
  - 彻底杜绝伪假图与像素模糊，手机相机、微信扫一扫毫秒级秒开识别。
- **智能回环 IP 穿透映射 (核心痛点解决)**：
  - 当在电脑本机通过 `127.0.0.1` 或 `localhost` 打开网页时，弹窗自动侦测并转换为电脑真实物理局域网 IP（`http://192.168.x.x:5000/`），彻底消除手机扫描回环地址无法连接的问题。
- **双引擎智能启动架构**：
  - **Python 智能启动器 (`launcher.py`)**：适合已装 Python 环境的开发与日常使用，支持自检与守护进程；
  - **PowerShell 原生启动器 (`launcher.ps1`)**：兼容 PowerShell 5.1/7+，无需安装 Python 或任何运行库，纯原生 Windows 开箱即用满血运行。
- **跨电脑一键免安装便携版打包**：
  - 双击 `打包便携发行版.bat`，即可一键生成全自包含的 `LAN-Fast-Share-Portable.zip`，可复制到任何未装 Python 的 Windows 电脑解压即用。
- **WebDAV 磁盘挂载**：原生兼容 WebDAV 协议，可在手机文件管理器（如 iOS "文件"、Android Solid Explorer）或 Windows 映射网络驱动器中直接挂载为本地磁盘。
- **拖拽任意目录共享**：支持将电脑上任意文件夹直接拖拽到 `.bat` 脚本上立即共享该目录。

## 🚀 快速上手

### 1. 首次配置（推荐，仅需一次）
右键点击 **`放行防火墙权限(首次右键管理员运行).bat`** 选择 **以管理员身份运行**。
> **作用**：将 `dufs.exe` 和 TCP 5000 端口加入 Windows 防火墙入站允许列表，防止 Windows 默认将 Wi-Fi 设为“公用网络”导致手机无法连接电脑。

### 2. 启动共享
- **方式 A（默认共享）**：直接双击运行 **`启动局域网快传.bat`**。
  - 自动检测并优先使用 Python 启动器，未装 Python 时自动切换至 PowerShell 原生启动器；
  - 自动在后台打开 `shared_files` 文件夹供您投放文件；
  - 控制台显示高对比度纯白静区二维码与访问网址。
- **方式 B（共享任意指定目录）**：将电脑上的任意文件夹直接拖动到 **`启动局域网快传.bat`** 文件图标上即可！

### 3. 一键便携版制作与跨电脑使用
- 双击运行 **`打包便携发行版.bat`**；
- 脚本会自动打包生成 `LAN-Fast-Share-Portable.zip`；
- 将压缩包拷至任何未安装 Python 的 Windows 电脑解压，双击 `启动局域网快传.bat` 即可满血使用！

## 📱 互传使用指南

### 1. 电脑 ➔ 手机（下载文件）
1. 电脑端将要发送的照片、视频、文档放入 `shared_files` 目录（或启动时拖拽的目录）；
2. 手机连接与电脑相同的 Wi-Fi 局域网；
3. 打开手机自带相机或微信“扫一扫”，扫描控制台中的二维码（或打开 `qrcode_guide.html` 引导页）；
4. 手机端网页即刻显示所有文件，点击即可高速下载；点击文件夹右侧按钮可直接**打包为 Zip 一键下载整个文件夹**。

### 2. 手机 ➔ 电脑（上传文件）
1. 手机扫码打开网页；
2. 点击网页顶部的 **`Upload`**（上传）按钮，选择手机相册中的照片、视频或本地大文件；
3. 上传进度实时显示，按 8 MiB 分段发送，支持当前页面任务暂停后继续；同路径重复任务会被跳过，已存在的同名文件需先重命名，避免误覆盖。

### 3. WebDAV 磁盘挂载（高级用法）
本服务原生支持 WebDAV，可将电脑共享目录直接映射为手机或另一台电脑的网络驱动器：
- **WebDAV 地址**：`http://<电脑局域网IP>:5000`
- **用户名 / 密码**：无需密码（开放读写）
- **客户端推荐**：
  - **iPhone / iPad**：打开自带「文件」App ➔ 右上角「连接服务器」➔ 输入 `http://<IP>:5000`；
  - **Android**：使用「MT 管理器」或「Solid Explorer」添加 WebDAV 存储；
  - **Windows**：此电脑 ➔ 映射网络驱动器 ➔ 输入网址。

## ❓ 常见问题排查 (FAQ)

### Q1: 手机扫码后显示“无法访问此网站”或连接超时？
1. **确认同一网络**：检查手机是否连接了同一个 Wi-Fi（注意部分路由器开启了“访客网络隔离”或 AP 隔离，请连接普通 2.4G/5G 频段）；
2. **防火墙拦截**：右键以管理员身份运行一次 `放行防火墙权限(首次右键管理员运行).bat`；
3. **电脑网络类型**：在 Windows 设置中将当前 Wi-Fi/以太网网络配置文件类型设为“专用网络”；
4. **代理软件 TUN 模式干扰**：部分 VPN / 代理工具开启全局 TUN 后可能会接管网络流量，启动器已内置过滤算法，请确认控制台输出的 IP 为物理路由器分配的网段（如 `192.168.x.x`）。

### Q2: 电脑浏览器打开时，手机扫码为什么不会连错成 127.0.0.1？
- 系统内置了**智能回环 IP 穿透映射机制**。即使在电脑浏览器地址栏使用 `http://127.0.0.1:5000` 或 `http://localhost:5000` 打开，网页在点击【📱 手机扫码】弹窗时，会自动将目标地址替换为电脑真实的局域网物理 IP（`http://192.168.x.x:5000/`），手机扫描直达电脑。
- 如果之前打开过网页，按一次 **`Ctrl + F5`** 强制刷新即可加载最新防缓存资产。

### Q3: 默认 5000 端口被占用了怎么办？
智能启动器内置**端口自适应顺延机制**，若 5000 端口已被其他程序占用，将自动递增探测并绑定可用端口（如 5001、5002），并在终端、扫码引导页及前端弹窗中同步更新。

## 大文件与多文件稳定性（2026-10-26）

- 网页上传和网页直接写盘下载分别最多并发 3 个；暂停收尾和最终提交仍占用槽位，避免旧写入与新任务交叉。
- 上传每段最多 8 MiB；HEAD 探测超时 10 s，下载等待网络连续 60 s 无进展时进入可重试错误状态。
- 支持直接写盘时，不再按 16 MiB 大小切换下载方式，也不累积 chunks 或创建整文件 Blob。每块写入成功后更新进度，再读取下一块，未知大小文件同样可下载。
- 单文件点击下载先选择保存位置；批量下载优先一次选择保存目录。没有目录选择接口时，在任务中逐项点击“选择保存位置”。批量保存发现已有同名文件会提示另选位置，不自动覆盖。
- 暂停会停止网络请求，等待当前磁盘写入结束后显示“已暂停”；继续使用已确认写入的偏移和 Range。版本校验失败、服务器不支持续传或未提供版本标识时，要求重新下载，避免错误追加。
- 浏览器通常先写磁盘临时文件，最终提交成功后才显示“已完成”。“正在保存”阶段需等待，暂停期间也不能把临时内容当作完整文件。取消会中止未提交写入；选择器可能已创建一个空文件，程序不会物理删除用户选择的目标。
- 任务只在当前页面有效；刷新、关闭页面或浏览器退出后不保留未提交写入的恢复能力。下载期间请勿通过其他程序改写源文件或目标文件。
- 任务列表每页 50 项，目录每页 200 项，进度最多每 200 ms 刷新一次。文本预览最多读取前 1 MiB；目录 JSON 仍一次返回，因此极大目录仍有解析、排序开销。

### 浏览器支持与原生兜底

直接保存需要 `showSaveFilePicker`、可写文件句柄及安全上下文，按运行时能力检测，不仅看浏览器名称。支持接口的桌面浏览器可通过 `http://localhost:<端口>` / `http://127.0.0.1:<端口>` 本机地址，或证书可信的 HTTPS 使用；localhost 指当前使用浏览器的那台设备，不能把手机上的 localhost 当作共享电脑地址。

手机或其他电脑通过普通 `http://192.168.x.x:<端口>` 访问通常不能使用该接口，将显示“已交给浏览器”。此后在浏览器下载列表管理进度、暂停、恢复及保存；实际能力和网络并发由浏览器决定。原生交接间隔至少 750 ms，批量下载可能需要允许多文件下载，也可使用打包下载。网页“全部暂停”无法暂停已交接的下载。

用户取消保存选择器时不下载；权限拒绝或磁盘写入失败会显示错误，不静默切换为另一份原生下载。本次未自动配置 HTTPS、安装证书或修改浏览器安全设置。

接口依据：[Chrome File System Access](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)、[安全上下文](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts)、[可写文件流](https://developer.mozilla.org/en-US/docs/Web/API/FileSystemFileHandle/createWritable)。
