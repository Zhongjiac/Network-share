# 🚀 局域网极速快传 (LAN Fast Share)

基于 Rust 高性能异步并发引擎 [sigoden/dufs](https://github.com/sigoden/dufs) 与智能物理网卡识别算法构建的局域网免客户端极速文件互传方案。无需安装微信/QQ，不耗费外网流量，支持手机、平板、电脑跨设备极速互联。

---

## 🌟 核心特性

- **现代化网盘级 UI（媲美 AList / 阿里云盘）**：
  - 100% 纯本地离线原生 ES6+/CSS3，零外网 CDN 与第三方网络依赖，断网也能秒开；
  - 现代毛玻璃质感与微动效，支持一键切换 **浅色模式 / 深色模式**；
  - 列表视图与网格视图（图片缩略图实时渲染）无缝切换；
  - 实时文件名过滤、排序（名称/大小/时间）与多级可点击面包屑导航；
  - 全屏高亮拖拽批量上传。
- **专业级传输任务中心**：
  - 右下角常驻悬浮胶囊，实时监控总上传/下载速度与进行中任务数；
  - 折叠抽屉面板分设【上传列表】与【下载列表】两个独立队列；
  - 实时进度条、已传/总大小、EWMA 算法平滑瞬时速率与精确剩余时间 (ETA)；
  - **断点续传与暂停/继续**：
    - **上传（真目录层级保持）**：支持文件多选、整目录上传与整目录全屏拖拽展开，自动保留完整相对路径层级，服务端自动递归创建缺失文件夹；基于 `HEAD` 探测服务端落盘字节 + `PATCH` 追加模式 (`X-Update-Range: append`)，暂停后点继续直接断点续传！
    - **下载**：自定义目录使用文件流直接写盘，支持当前页面内暂停和续传；浏览器默认路径下，已知大于 50 MiB 的文件交给浏览器，其余文件在网页接收后交给浏览器保存。
    - **保存位置**：支持自定义下载目录及每次逐个选择保存位置；接口不可用时明确提示，可主动选择浏览器下载。
  - 全局队列控制：【全部暂停】、【全部开始】、【清空已完成】，网页上传最多 3 并发、下载最多 2 并发；已交给浏览器的下载由浏览器管理。
- **多选与悬浮批量操作坞 (Batch Action Dock)**：
  - 支持单选、全选与 `Shift` 键连选，底部平滑滑出操作坞，支持批量流式下载、批量删除与打包下载。
- **多媒体与代码在线预览 (Lightbox)**：
  - 支持图片大图查看、音视频 HTML5 流媒体即时点播（支持 Range 拖动秒播）、文本/代码等宽高亮查看。
- **精准物理网卡识别算法**：
  - 智能算法自动剔除 WSL、VMware、VirtualBox、VPN、Npcap、蓝牙及 Clash/代理 TUN 等虚拟网卡，100% 精准锁定路由器分配的真实物理局域网 IP。
- **100% 离线纯矢量高保真二维码引擎 (全新升级)**：
  - 前端内置轻量纯原生 JS QR 算法引擎，严格遵循 ISO/IEC 18004 国际标准，配置 4 模块纯白安全静区与 M 级纠错；
  - 彻底杜绝伪假图与像素模糊，手机相机、微信扫一扫毫秒级秒开识别。
- **智能回环 IP 穿透映射 (核心痛点解决)**：
  - 当在电脑本机通过 `127.0.0.1` 或 `localhost` 打开网页时，弹窗自动侦测并转换为电脑真实物理局域网 IP（`http://192.168.x.x:5000/`），彻底消除手机扫描回环地址无法连接的问题。
- **双引擎智能启动架构（启动自动开网页）**：
  - **Python 智能启动器 (`launcher.py`)**：适合已装 Python 环境的开发与日常使用，启动后自动打开本机复制入口，手机使用终端二维码中的局域网地址，支持自检与守护进程；
  - **PowerShell 原生启动器 (`launcher.ps1`)**：兼容 PowerShell 5.1/7+，无需安装 Python 或任何运行库，纯原生 Windows 开箱即用满血运行，同样支持启动自动唤起浏览器。
- **跨电脑一键免安装便携版打包**：
  - 双击 `打包便携发行版.bat`，即可一键生成全自包含的 `LAN-Fast-Share-Portable.zip`，可复制到任何未装 Python 的 Windows 电脑解压即用。
- **WebDAV 磁盘挂载**：原生兼容 WebDAV 协议，可在手机文件管理器（如 iOS "文件"、Android Solid Explorer）或 Windows 映射网络驱动器中直接挂载为本地磁盘。
- **拖拽任意目录共享**：支持将电脑上任意文件夹直接拖拽到 `.bat` 脚本上立即共享该目录。

## 🚀 快速上手

### 1. 首次配置（推荐，仅需一次）
右键点击 **`放行防火墙权限(首次右键管理员运行).bat`** 选择 **以管理员身份运行**。
> **作用**：将 `dufs.exe` 和 TCP 5000 端口加入 Windows 防火墙入站允许列表，防止 Windows 默认将 Wi-Fi 设为“公用网络”导致手机无法连接电脑。

### 2. 启动共享
- **方式 A（默认共享）**：直接双击运行 **`启动局域网快传.bat`**。
  - 自动检测并优先使用 Python 启动器，未装 Python 时自动切换至 PowerShell 原生启动器；
  - 自动在后台打开 `shared_files` 文件夹供您投放文件；
  - 控制台显示高对比度纯白静区二维码与访问网址。
- **方式 B（共享任意指定目录）**：将电脑上的任意文件夹直接拖动到 **`启动局域网快传.bat`** 文件图标上即可！

### 3. 一键便携版制作与跨电脑使用
- 双击运行 **`打包便携发行版.bat`**；
- 脚本会自动打包生成 `LAN-Fast-Share-Portable.zip`；
- 将压缩包拷至任何未安装 Python 的 Windows 电脑解压，双击 `启动局域网快传.bat` 即可满血使用！

## 📱 互传使用指南

### 1. 电脑 ➔ 手机（下载文件）
1. 电脑端将要发送的照片、视频、文档放入 `shared_files` 目录（或启动时拖拽的目录）；
2. 手机连接与电脑相同的 Wi-Fi 局域网；
3. 打开手机自带相机或微信“扫一扫”，扫描控制台中的二维码（或打开 `qrcode_guide.html` 引导页）；
4. 手机端网页即刻显示所有文件，点击即可高速下载；点击文件夹右侧按钮可直接**打包为 Zip 一键下载整个文件夹**。

### 2. 手机 ➔ 电脑（上传文件）
1. 手机扫码打开网页；
2. 点击网页顶部的 **`Upload`**（上传）按钮，选择手机相册中的照片、视频或本地大文件；
3. 先显示“正在读取文件 · 计算 SHA-256”，再按 8 MiB 分段上传；发送完毕显示“正在校验 SHA-256”，源文件与服务端哈希一致才完成。支持当前页面任务暂停后继续；已有同名文件需先重命名。

### 3. WebDAV 磁盘挂载（高级用法）
本服务原生支持 WebDAV，可将电脑共享目录直接映射为手机或另一台电脑的网络驱动器：
- **WebDAV 地址**：`http://<电脑局域网IP>:5000`
- **用户名 / 密码**：无需密码（开放读写）
- **客户端推荐**：
  - **iPhone / iPad**：打开自带「文件」App ➔ 右上角「连接服务器」➔ 输入 `http://<IP>:5000`；
  - **Android**：使用「MT 管理器」或「Solid Explorer」添加 WebDAV 存储；
  - **Windows**：此电脑 ➔ 映射网络驱动器 ➔ 输入网址。

## ❓ 常见问题排查 (FAQ)

### Q1: 手机扫码后显示“无法访问此网站”或连接超时？
1. **确认同一网络**：检查手机是否连接了同一个 Wi-Fi（注意部分路由器开启了“访客网络隔离”或 AP 隔离，请连接普通 2.4G/5G 频段）；
2. **防火墙拦截**：右键以管理员身份运行一次 `放行防火墙权限(首次右键管理员运行).bat`；
3. **电脑网络类型**：在 Windows 设置中将当前 Wi-Fi/以太网网络配置文件类型设为“专用网络”；
4. **代理软件 TUN 模式干扰**：部分 VPN / 代理工具开启全局 TUN 后可能会接管网络流量，启动器已内置过滤算法，请确认控制台输出的 IP 为物理路由器分配的网段（如 `192.168.x.x`）。

### Q2: 电脑浏览器打开时，手机扫码为什么不会连错成 127.0.0.1？
- 系统内置了**智能回环 IP 穿透映射机制**。即使在电脑浏览器地址栏使用 `http://127.0.0.1:5000` 或 `http://localhost:5000` 打开，网页在点击【📱 手机扫码】弹窗时，会自动将目标地址替换为电脑真实的局域网物理 IP（`http://192.168.x.x:5000/`），手机扫描直达电脑。
- 如果之前打开过网页，按一次 **`Ctrl + F5`** 强制刷新即可加载最新防缓存资产。

### Q3: 默认 5000 端口被占用了怎么办？
智能启动器内置**端口自适应顺延机制**，若 5000 端口已被其他程序占用，将自动递增探测并绑定可用端口（如 5001、5002），并在终端、扫码引导页及前端弹窗中同步更新。

## 本机复制与上传 SHA-256（2026-11-01）

### 共享电脑本机使用

重启启动器后，默认浏览器打开 `http://127.0.0.1:<本机入口端口>`，前端仍显示“上传文件/上传文件夹”。选择文件后，辅助程序调用 Windows CopyFileEx 直接复制到当前共享子目录，文件内容不经过 HTTP 上传，不操作系统剪贴板，也不移动源文件。复制完成后分别计算源文件和临时目标的 SHA-256，一致才提交最终名称。任务显示复制进度、读取/校验进度和两个哈希值。

两个启动器共用 `native-helper.ps1` / `native-helper.cs`，依赖 Windows 自带的 Windows PowerShell/.NET，无需额外安装 Python。辅助接口仅监听回环地址，和启动器一起退出；本机页面通过同源代理访问 dufs。大文件哈希读取需要额外磁盘时间，这部分与复制或上传耗时分开显示。

- 共享目录已有同名文件会报错，不自动覆盖；同源同目标只校验并跳过重复复制。
- 目录复制保留相对层级和空目录。复制任务串行执行，可取消，不提供暂停；“全部暂停”作用于网页上传/下载。
- 本机拖放不能取得完整 Windows 源路径，因此会提示使用上传文件/文件夹按钮选择源文件。
- 本机使用启动器自动打开的回环地址；局域网地址保持网络上传方式。页面不额外增加复制或网络上传分流按钮。
- 手机和其他电脑继续访问二维码中的局域网地址，不能使用它们自己的 localhost 访问共享电脑。本机辅助服务不可用时，网络服务仍可独立使用，但不代表本机复制可用。

### 网络上传

流程为“排队 → 正在读取文件/计算 SHA-256 → 上传中 → 正在校验 → 已完成/失败”。浏览器使用 Worker 每次读取 4 MiB 计算增量 SHA-256，不要求 HTTPS，不把整文件读入内存。准备阶段不会发起上传，也不显示上传速度和 ETA；真正发送数据后才计算上传速度。

所有字节发送成功后，读取 dufs `?hash` 的服务端完整文件 SHA-256。只有哈希一致才显示“已完成，SHA-256 一致”；详情可展开查看源和目标值。失败不自动删除目标文件，需根据错误处理。源哈希读取和服务端哈希请求分别串行排队，避免大量大文件同时校验磁盘。刷新页面后不保留哈希和传输任务。

## 下载行为与验证（2026-11-01）

### 保存位置

- 开启“每次询问”时优先使用单文件保存选择器；单文件点击直接弹出，批量任务逐项点击“选择保存位置”。用户取消后不开始下载。
- 未开启询问时，使用配置的自定义目录；该目录已有同名文件会报错并提示另选位置，不自动覆盖。本页面任务也不能同时写入同一个目标。
- 系统保存对话框中明确确认替换已有文件时，才允许该次覆盖。权限拒绝、创建写入流、写入或最终提交失败会显示错误，不自动换成另一份下载。
- 未选择自定义目录时沿用浏览器默认路径：已知大于 50 MiB 的文件直接交接；其余文件在网页接收后以 Blob 交给浏览器保存。未知大小且未返回 Content-Length 的文件也可能在内存中累积，应优先使用直接写盘方式。

保存选择器与自定义目录需要浏览器提供 File System Access API，普通局域网 HTTP 地址通常不能使用。支持接口的浏览器可通过共享电脑本机的 localhost / 127.0.0.1，或证书可信的 HTTPS 使用。其他设备上的 localhost 指向其他设备自身。接口不支持时，相应设置不可启用；已有“每次询问”偏好仍会等待明确选择，可主动点击“使用浏览器下载”。

### 暂停、继续与完成状态

- 自定义目录或单文件选择器下载直接写盘，不累积整文件 Blob。暂停会中止网络并等待在途写入完成，保留临时写入流；继续从已成功写入的偏移请求 Range。
- 网络错误后可以继续重试。版本标识缺失/变化、Range 不匹配或不支持续传时，丢弃旧临时内容并归零重新下载。磁盘错误会丢弃临时写入，同步归零，避免追加到错误偏移。
- 只有文件写入及最终 close 成功、已知大小与接收长度一致，才显示“已完成”。这不等于对源文件做了密码学哈希校验。
- 原生交接统一显示“已交给浏览器”，不伪造 100% 或声称已保存完成。交接间隔至少 750 ms；批量下载可能需要浏览器允许多文件下载。实际进度、暂停、取消、失败和保存结果在浏览器下载列表查看，网页只能移除记录。
- 下载任务仅在当前页面有效；刷新或关闭页面后不保证恢复。取消会中止未提交写入；选择器可能已创建空文件，程序不会物理删除目标。暂停期间的临时文件不能视为完整文件。
- 网页上传最多 3 并发，下载最多 2 并发；正在暂停、写入收尾仍占槽位。上传每段最多 8 MiB，HEAD 探测超时 10 s，网络无进展超时 60 s。操作系统磁盘 I/O 若长期不返回，程序仍需等待，不能强制中止。
- 任务列表每页 50 项，目录每页 200 项；文本预览最多读取前 1 MiB。目录 JSON 仍整体返回。
